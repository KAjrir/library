# Library

A small book library app built as part of [The Odin Project](https://www.theodinproject.com/).

🔗 **Live demo:** https://kajrir.github.io/library/

## Features
- Add books (title, author, pages) through a form
- Track the reading status: not read yet, reading or read
- Delete books

## Built with
HTML, CSS and JavaScript (ES6 classes)

## What I learned
- Refactoring constructor functions into `class Book` and `class Library`
- Keeping data (the library array) separate from rendering
